# 📊 Telecom Customer Churn EDA

This project focuses on **Exploratory Data Analysis (EDA)** of a Telecom Customer Churn dataset to identify the major factors affecting customer churn and uncover meaningful business insights.

---

# 📌 Project Objective

The main goal of this analysis is to:

- Understand customer behavior
- Identify churn patterns
- Discover key factors responsible for customer loss
- Generate insights that can help telecom companies improve customer retention

---

# 📂 Dataset Information

The dataset contains telecom customer details such as:

- Customer demographics
- Services subscribed
- Contract type
- Payment methods
- Monthly & total charges
- Internet services
- Customer tenure
- Churn status

# 🔍 Key Insights

- Customers with **month-to-month contracts** show the highest churn.
- Customers with **higher monthly charges** are more likely to churn.
- **Short tenure customers** have higher churn rates.
- Lack of **online security services** increases churn probability.
- Customers using **electronic check payment methods** churn more frequently.

---

# 📊 Conclusion

The EDA reveals strong relationships between customer churn and factors like contract type, tenure, monthly charges, and additional services. These insights can help telecom companies take proactive steps to reduce churn and improve customer satisfaction.
